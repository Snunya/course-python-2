# Async Docx to Markdown Converter API (Variant 2)

HTTP API сервис для асинхронного преобразования файлов Docx в формат Markdown.

## Команды проекта
- make install  : установка зависимостей
- make samples  : программная генерация 4 входных docx-файлов
- make lint     : проверка оформления PEP8 и сложности
- make test     : запуск тестов
- make coverage : построение отчета о покрытии веток
- make run      : запуск веб-сервера
